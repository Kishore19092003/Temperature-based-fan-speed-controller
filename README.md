# Temperature-Based Fan Speed Controller

## 📌 Project Overview

The **Temperature-Based Fan Speed Controller** is an automatic temperature monitoring and fan control system designed to regulate fan operation based on the surrounding temperature.

The system uses an **Arduino Uno**, **DS18B20 temperature sensor**, relay module, LCD display, and fan to monitor temperature and automatically control the fan according to the detected temperature.

## 🎯 Objectives

* To develop an automatic temperature-based fan control system.
* To continuously monitor the surrounding temperature.
* To automatically control the fan based on temperature.
* To reduce unnecessary power consumption.
* To improve user convenience and system efficiency.

## 🔧 Components Used

* Arduino Uno
* DS18B20 Temperature Sensor
* Relay Module
* DC Fan
* 16×2 LCD Display with I2C
* Power Supply
* Connecting Wires

## ⚙️ Working Principle

The **DS18B20 temperature sensor** continuously measures the surrounding temperature and sends the temperature data to the Arduino Uno.

The Arduino processes the temperature reading and controls the fan through a relay module. When the temperature reaches the predefined threshold, the fan is automatically switched ON. When the temperature decreases below the required level, the fan is switched OFF.

The **16×2 LCD display** shows the measured temperature and the current fan status.
